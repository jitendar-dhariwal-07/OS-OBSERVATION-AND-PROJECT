=== TSCOS v1.0 : interactive mode ===
Commands:
  density N S E W     set vehicle counts for the four approaches
  rush 0|1            turn rush-hour profile off/on
  emergency N|S|E|W   emergency vehicle on an approach (preempts)
  ped N|S|E|W         pedestrian button pressed at a crossing
  override N|S|E|W    police force one approach green
  release             release police override (safe transition)
  help                show this list
  quit                stop the system
